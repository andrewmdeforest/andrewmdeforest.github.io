alfred: privacy policy

alfred is a private backup tool used by a single person, its owner, to back up his own files to his own Google Drive account.

What alfred accesses

With the owner's consent, alfred uses the Google Drive scope drive.file. This scope only allows access to files and folders that alfred itself created. alfred cannot see or read any other file in the Drive account.

What alfred does with data

The files alfred uploads are encrypted before they leave the owner's computer. alfred does not collect, share, sell or transmit any data to any third party, and has no users other than its owner. The access token Google issues is stored only on the owner's own computer.

Google API Services User Data Policy

alfred's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke alfred's access at any time in the Google account's security settings, under third-party access.
